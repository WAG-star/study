## 核心记忆点速览

- 私钥是钥匙，公钥是锁——锁放服务器，钥匙随身带
- 公钥管"进门"，密码管"管事"；公钥可关密码登录，关不掉 sudo 验证
- 服务器安全三件套 = 关 root 密码门 + 开防火墙 + 留好逃生通道
- 提示符就是 shell 的化身——看到 `$`/`#`，你就已经在 shell 里了
- `ps aux | grep xxx` 结果里永远有一行 grep 自己，看到别慌
- `&` 防"占着终端"，`nohup` 防"断开被杀"
- grep 空结果三查：文件有没有内容？条件格式对不对？逐步放宽条件
- awk 数列适合格式固定日志；格式会变时用 `grep -oE` 抓形状
