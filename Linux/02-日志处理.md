# Day2：日志三件套（grep / awk / vim）

> 目标：会查日志——报错能定位、统计能上手
> 评分：96/100（实操空结果排查 + awk 转义扣分，已纠正）

## 1. 日志在哪

| 文件 | 内容 |
|------|------|
| `/var/log/auth.log` | 登录/认证日志（谁登录、成功/失败） |
| `/var/log/syslog` | 系统综合日志 |
| `/var/log/kern.log` | 内核日志 |
| 应用日志 | 各程序自己的（如 nginx 的 `/var/log/nginx/access.log`） |

## 2. tail —— 看尾部（日志追加写，最新在尾部）

```bash
tail -20 /var/log/auth.log     # 最后 20 行
tail -f /var/log/auth.log      # 实时跟踪（Ctrl-C 停）
```

## 3. grep 五连

```bash
grep "error" /var/log/syslog      # 找含 error 的行
grep -i "error" file              # -i 忽略大小写
grep -v "debug" file              # -v 排除（反向）
grep -c "error" file              # -c 只输出计数
grep -E "error|fail" file         # -E 正则
grep -A2 -B2 "error" file         # 上下文（匹配行 ± 2 行）
grep -r "error" /var/log/         # -r 递归目录
grep -oE '正则' file              # -o 只输出匹配的部分
```

💡 **记忆**：查报错标配 `grep -A5 -B5 "error" xxx.log`——前后各 5 行看来龙去脉。

## 4. awk —— 取列

```bash
awk '{print $1}' file        # 第 1 列（默认空格分隔）
awk '{print $1, $3}' file    # 第 1、3 列
awk '{print $NF}' file       # 最后一列（NF = 列数）
awk '$1 == "error"' file     # 条件过滤
```

⚠️ **易错点（实测翻车）**：awk 表达式用**单引号**包，里面 `$10` **直接写，不要加反斜杠**。`awk '{print \$10}'` 会报语法错误——单引号内的 `$` 不会被 bash 展开，无需转义。

⚠️ **易错点（列漂移）**：日志格式不固定时（如 `Failed password for root` vs `Failed password for invalid user xxx` 差两个词），**列号会漂移**。别硬数列，改用正则抓 IP：

```bash
grep "Failed password" /var/log/auth.log | grep -oE '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' | sort | uniq -c | sort -rn | head -5
```

💡 **记忆**：awk 数列适合格式固定的日志；格式会变时用 `grep -oE` 直接"抓形状"。

## 5. sort + uniq —— 排序去重计数

```bash
sort file          # 排序
sort -n file       # 按数字排序
uniq -c file       # 去重并计数（必须先 sort！）
sort -rn           # -r 降序 -n 数字
```

⚠️ **易错点**：`uniq` 只合并**相邻**重复行——不先 `sort` 就 `uniq -c`，相同项分开就计不了数。统计永远 `sort | uniq -c`。

## 6. vim —— 大日志阅读器

```bash
vim /var/log/auth.log
```

| 操作 | 按键 |
|------|------|
| 搜索 | `/关键字` 回车，`n` 下一个，`N` 上一个 |
| 文件头/尾 | `gg` / `G` |
| 显示行号 | `:set nu` |
| 删除一行 / 撤销 | `dd` / `u` |
| 保存退出 / 不保存退出 | `:wq` / `:q!` |

💡 **记忆**：vim 查日志三板斧：`/` 搜、`n` 跳、`gg/G` 定位。只读查看永远 `:q!` 退出。

## 7. 管道链六连招（万能统计模板）

```
grep 筛选 → awk 取列/条件 → sort 排序 → uniq -c 去重计数 → sort -rn 降序 → head 取前 N
```

```bash
# 统计 auth.log 里登录失败来源 IP TOP5
grep "Failed password" /var/log/auth.log | awk '{print $10}' | sort | uniq -c | sort -rn | head -5

# 更稳版（防列漂移，用正则抓 IP）
grep "Failed password" /var/log/auth.log | grep -oE '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' | sort | uniq -c | sort -rn | head -5

# 只统计"成功登录"的来源（扫描器进不了这个名单）
grep "Accepted" /var/log/auth.log | grep -oE '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' | sort | uniq -c | sort -rn
```

## 8. 实战记录（服务器实测）

当天 auth.log 505 行认证日志，TOP5 来源：
```
16 139.19.117.129    ← 扫描器
 9 8.217.180.182     ← 爆破者（撞 root 密码）
 6 47.92.1.193       ← 扫描器
 4 140.206.252.177   ← 用户自己（Last login 来源）
 3 8.222.180.55      ← 扫描器
```

关键日志解读：
- `Failed password for root from <IP>` = 有人在撞 root 密码（Day0 已收紧 `PermitRootLogin prohibit-password` 挡住）
- `Failed password for invalid user test` = 扫描器在枚举用户名（root/admin/test...）
- `message repeated 4 times: [...]` = rsyslog 重复抑制，实际尝试次数更多
- `Accepted password for wag from <IP>` = 成功登录

💡 **记忆**：公网服务器 100% 被扫，安全基线不是杞人忧天，是基本生存技能。`Accepted`=成功、`Failed`=失败。

## 9. 空结果排查三查

```
① 文件有没有内容？   wc -l file / tail -5 file
② 条件格式对不对？   日期格式、关键字大小写
③ 逐步放宽条件？     先 grep -ci "error" 全文件，再加日期条件
```

💡 **记忆**：grep 无输出 ≠ 命令错，可能是数据里没有匹配（正常系统没有 error 是好事）。
