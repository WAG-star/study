# C 语言学习笔记

> 面向系统编程 / 数据库内核方向 · 前 8 周期知识字典（完整交付）
> 学习方式：5 概念/组 → 讲解 → 练习 → 逐题批改（10 分制）

## 核心主线

前 8 周期本质围绕 **「内存」与「地址」** 展开的四块拼图：内存管理 → 指针系统 → 位运算 → 工程架构。

---

## 1. 存储类别与类型控制

| 关键字 | 要点 |
|--------|------|
| `static` | 修饰局部变量：生命周期延至程序结束（静态数据区）；修饰全局变量/函数：内部链接，仅限当前 `.c` 文件 |
| `const` | `const int *p`（左定值）：指向的内存不可变；`int * const p`（右定向）：指针指向不可变 |
| `register` | C11 已废弃，原意存寄存器，现由编译器图着色算法接管 |
| `extern` | 声明符号在其他文件定义，链接期跨文件寻址 |
| `unsigned` | 右移执行**逻辑右移**（高位补 0）；有符号数执行**算术右移**（高位补符号位） |
| `void` | `void *` 泛型盲盒指针，解引用前**必须强转** |
| `sizeof` | 编译期运算符。`sizeof(数组)`=总大小；`sizeof(指针)` 64 位下恒为 8 |

💡 **记忆**：局部管寿命，全局管边界（C 实现私有化的唯一方式）。

---

## 2. 内存管理与字符串操作

| 函数 | 要点 |
|------|------|
| `malloc(size)` | 堆区分配未初始化内存，失败返回 `NULL` |
| `calloc(nmemb, size)` | 堆区分配并全量清零 |
| `realloc(ptr, size)` | 调整堆内存，可能原地扩容或搬迁（返回新地址） |
| `free(ptr)` | 释放堆内存，必须配合 `ptr = NULL` 防 Double Free / Use-After-Free |
| `memset(ptr, val, size)` | **按字节**赋值，不能初始化 int 数组为非 0/-1 |
| `memmove(dest, src, size)` | 安全处理内存重叠 |
| `strlen / strcpy / strcat / strcmp` | 警惕 `\0` 截断与越界；`strcmp` 相等返回 0，禁止用 `==` 比内容 |

💡 **记忆**：堆内存像租房，`malloc` 签合同，`free` 退租并销毁钥匙。

---

## 3. 指针与结构体进阶

- **`*` / `&`**：解引用 / 取地址
- **`->`**：结构体指针访问成员，等价于 `(*ptr).member`
- **二级指针 `**`**：存储"指针的地址"。核心场景：统一链表删除逻辑（指向"上一个节点的 next 指针本身"），消除头节点 `if` 特判
- **结构体对齐**：成员按"从大到小"排列最小化 Padding；`sizeof` 是最大对齐数的整数倍
  - 💡 超市货架原则：8 字节 double 必须放 8 的倍数地址，否则 CPU 机械臂要抓两次
- **柔性数组**：`char data[];` 须为末位成员，分配公式 `malloc(sizeof(struct) + 额外字节)`

💡 **记忆**：一级找数据，二级改指针；`void *` 是万能通行证但使用前必须验明正身（强转）。

---

## 4. 位运算与补码机制

| 运算 | 用途 |
|------|------|
| `&` | 掩码提取（`x & 1` 判奇偶）或配合 `~` 清零 |
| `\|` | 强制置 1（`x \| (1<<n)`） |
| `^` | `x ^ x = 0`, `x ^ 0 = x`；无临时变量交换、找单身狗 |
| `~` | 配合 `&` 制作清零模具：`x &= ~(1<<n)` |
| `<<` | 低位补 0，相当于乘 2 |
| `>>` | 无符号逻辑右移（补 0）；有符号负数算术右移（补 1，`-1` 永远 `-1`） |
| 补码 | 负数表示，`-1` 为全 1 |

💡 **记忆**：位运算是精准外科手术，`|` 置 1，`&~` 清零，`^` 消消乐（成对消消乐，剩下的就是单身狗），补码是负数的防弹衣。

## 5. 预处理器与宏魔法

- **`#define`**：纯文本替换。**铁律**：参数和整体必须加括号 `#define SQUARE(x) ((x)*(x))`
- **`#ifndef / #define / #endif`**：头文件防卫式声明
- **`#`（字符串化）**：`#x` → `"x"`
- **`##`（记号拼接）**：`func_##name` → `func_test`

💡 **记忆**：宏是盲目的文本替换，括号是唯一的护城河。

---

## 6. 架构、泛型与系统调用

| 机制 | 要点 |
|------|------|
| `typedef` | 简化函数指针：`typedef int (*cmp)(int, int);` |
| 函数指针 | `返回值 (*指针名)(参数)`，指向代码段入口，实现回调 |
| `qsort` | `void *` 接收数据 + 比较函数（验货员）实现多态排序 |
| `fopen / fwrite / fgets` | 文件 I/O；`fgets` 自带防溢出（读 size-1 字符加 `\0`） |
| `perror(msg)` | **铁律**：必须在系统调用失败的**第一现场**立即调用，防 `errno` 被覆盖 |

💡 **记忆**：`void *` + 函数指针 = C 语言的多态；`perror` 是案发现场的法医，迟了就失效。

---

## 7. 回调机制原理（综合串联）

**万能插座 (`void*`) + 验货员 (函数指针)**：`qsort` 像盲盒流水线，用 `void*` 接收数据不知道类型，靠比较函数强转回真实类型对比大小。算法框架固定，具体行为由外部注入 = 多态雏形。

**经典场景题**（综合检验 42/50 后巩固）：
1. 柔性数组 + 对齐优化：网络包结构体成员排序最小化 Padding，`malloc(sizeof(struct Packet) + 100)`
2. 二级指针链表删除：`struct Node **indirect` 遍历，无头节点特判
3. 泛型回调排序：`qsort` + `cmp_score` 降序（`return *(int*)b - *(int*)a;`）
4. 位清零宏：`#define CLEAR_BIT(x, n) ((x) &= ~(1 << (n)))`
5. 补码右移：`int b = -1 >> 1` → -1；`(unsigned int)-1 >> 1` → 极大正数（逻辑右移）

## 8. 易错点清单（错题轰炸记录）

- [x] `x &= 1` 是赋值运算，判断奇偶只用 `x & 1`（宏里 `&=` 会改外部变量）
- [x] 清零必须 `& ~(1<<n)`，不能用 `^`（不知道目标位当前是 0 还是 1）
- [x] `-1` 补码全 1，算术右移永远 `-1`；想补 0 先强转 `unsigned`
- [x] 异或交换：`b = (a^b)^b = a`（成对消消乐，剩下的就是单身狗）
- [x] typedef 类型名 vs 变量名：`typedef void (*EventHandler)(int); EventHandler handler;`
- [x] `perror` 必须在失败第一现场（紧挨 fopen），否则 errno 被覆盖
- [x] `memset` 按字节赋值：`memset(arr, 1, ...)` → int 数组得到 `0x01010101` = 16843009
- [x] 宏 `MUL(2+3, 4)` 不加括号 = 14 不是 20；`#define MUL(a,b) ((a)*(b))`
- [x] 静态局部变量：`static int c` 跨调用保留值（1 2 3）；删掉 static 每次重置（1 1 1）
